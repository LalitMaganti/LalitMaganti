Senior Staff Software Engineer at Google, working on [Perfetto](https://docs.perfetto.dev), an open source suite of tools for performance tracing and analysis.

Before Google, I contributed to Android custom ROMs (CyanogenMod, OmniROM) and built open source Android apps,
including [HoloIRC](https://github.com/Lalitmaganti/HoloIRC).

I'm passionate about performance, open-source, and especially the intersection
of the two. I'm also generally interested in AI/LLMs and how they are
changing the software engineering industry.
